# 業務提案版觀察語句庫

> 各種情境下的標準觀察措辭。
> 直接複製改成客戶情境即可使用。

---

## 1. 文章 / 內容缺位類

| 情境 | 建議措辭 |
|------|---------|
| 知識文章太少 | 「目前 [關鍵字] 的搜尋需求疑似缺少對應的知識內容承接，AI 被問到相關問題時，可能引用競品而非自身內容」 |
| 文章標題年份過時 | 「部分文章疑似有時效性問題，建議確認標題年份與實際更新狀況是否一致」 |
| 分類頁缺位 | 「目前 [關鍵字] 相關的搜尋結果傾向呈現商品集合頁，但品牌網站疑似缺少對應的分類入口」 |
| 內容深度不足 | 「目前部分文章與競業相比，可能在 [關鍵字] 的內容深度上仍有補強空間，影響 AI 引用該主題時的選擇」 |
| 知識主題覆蓋不全 | 「品牌的核心商品/服務 [描述] 在 AI 知識覆蓋上疑似有缺口，使用者向 AI 詢問相關問題時，可能無法精確識別品牌」 |

---

## 2. 品牌識別訊號類

| 情境 | 建議措辭 |
|------|---------|
| 首頁 Title 異常 | 「官網首頁的標題設定疑似非品牌名稱，AI 掃描首頁時可能無法正確識別品牌主體」 |
| H1 為 og-fallback | 「頁面主標題的語意設定疑似不完整，AI 判斷頁面主題時，可能無法精確識別品牌定位」 |
| 多重 H1 | 「部分頁面同時存在多個主標題（H1），AI 判斷主題訊號可能混淆」 |
| llms.txt 缺席 | 「目前網站疑似未設置 llms.txt（給 AI 看的網站簡介），AI 引擎難以快速建立品牌識別框架」 |
| Organization Schema 缺席 | 「品牌組織資訊（Organization Schema）疑似未設定，影響搜尋結果中品牌知識面板的呈現機會」 |
| ProfilePage Schema 缺席 | 「專業人員介紹頁疑似缺少結構化的學經歷標記與外部佐證連結，AI 在引用品牌專業權威時，可能無法精確識別」 |

---

## 3. AI 引用結構類

| 情境 | 建議措辭 |
|------|---------|
| Meta 描述重複 | 「多個商品/分類頁面疑似使用相同描述，AI 難以辨別各頁差異化特色，限制了各頁的精確推薦機會」 |
| Meta 多樣性低 | 「目前頁面 Meta Description 多樣性疑似偏低，AI 在區分各頁面內容時，可能難以精確識別差異」 |
| FAQ Schema 缺位 | 「FAQ 頁面疑似缺少對應的 FAQ 結構化資料，AI 在引用問答內容時，可能無法精確識別問題與答案的對應關係」 |
| Product Schema 不完整 | 「產品頁面的 Product Schema 覆蓋率疑似不完整，AI 被問到價格或現貨時，可能無法精確引用商品資訊」 |
| AIO 知識 vs 品牌落差 | 「品牌已有 [X] 個知識型 AIO 關鍵字，但品牌推薦型問句幾乎空白——消費者看完知識後問 AI 推薦品牌，品牌尚未建立對應的語意識別框架」 |

---

## 4. 技術 SEO 類（業務版只說有/沒有，不深入）

| 情境 | 建議措辭 |
|------|---------|
| Soft 404 | 「部分下架或失效頁面疑似未正確回傳 404 狀態碼，可能導致 AI 爬蟲持續造訪空頁面，浪費爬取資源」 |
| URL 一致性 | 「同一頁面存在多個可訪問的網址，可能導致 AI 爬蟲與搜尋引擎的信任訊號分散」 |
| 首頁多版本 | 「網站首頁疑似存在多個可訪問的網址版本，建議確認是否需要設定主要版本」 |
| Cross-canonical | 「部分頁面的 canonical 設定指向異常，建議確認是否為刻意設定」（注意：必須先 curl 確認非尾斜線誤報） |
| noindex 涉及知識頁 | 「部分疑似具有知識價值的頁面被設為不可收錄，AI 爬蟲無法讀取其中內容」 |
| Sitemap 過時 | 「Sitemap 可能未即時反映網站現況，新頁面被 AI 爬蟲發現的速度可能延遲」 |

## 5. 圖片 Alt（不放主痛點，僅輔助說明）

放在三大痛點區塊**結尾的灰色提示框**：

> 💡 **圖片 Alt 覆蓋率 [X]%**（[已標記/總圖片] 張），[業態] 高度依賴 [產品照/案例圖/視覺素材] 的視覺說服力，建議優先為 [建議優先補的圖片類型] 補上 Alt 說明文字。

## 6. 文章新鮮度類

| 情境 | 建議措辭 |
|------|---------|
| 文章過時 | 「部分知識文章可能因時效性不足，在 AI 偏好新鮮內容的排序機制下，被較新的競品內容取代」 |
| dateModified 未同步 | 「文章的結構化資料（dateModified）建議與實際更新同步，幫助搜尋引擎與 AI 識別最新資訊」 |
| 標題年份過時 | 「文章標題仍含過時的年份標記，可能讓使用者與搜尋引擎誤判內容時效」 |

---

## 7. E-E-A-T 與外部訊號

| 情境 | 建議措辭 |
|------|---------|
| 外部連結不足 | 「目前網站在品牌權威性的外部佐證（如媒體報導、專業機構連結）方面尚有建立空間，有助於提升 AI 推薦時的信賴度判斷」 |
| 集中度不足 | 「品牌缺少集中的外部聲量經營策略（如 Google 商家、社群、媒體合作），AI 在判斷品牌可信度時可能訊號分散」 |
| 連結誘餌缺位 | 「品牌缺少容易吸引外連的內容資產（如免費範本、計算器、產業調查），長期影響域名權威建立速度」 |

---

## 8. 服務型品牌專屬

| 情境 | 建議措辭 |
|------|---------|
| 缺乏 E-E-A-T 結構化 | 「專業人員介紹頁疑似缺少結構化的學經歷標記與外部佐證連結，AI 在引用品牌專業權威時，可能無法精確識別」 |
| 缺乏 CTA | 「文章與服務頁面間的 CTA 連結疑似不夠醒目，可能影響使用者從知識內容轉換為諮詢的機會」 |
| 首頁差異化不明確 | 「首頁疑似未明顯傳達服務特色，使用者可能無法快速感受品牌差異」 |
| 客戶見證頁不足 | 「客戶見證/民眾回饋頁面疑似缺少結構化的引用標記，影響 AI 對品牌口碑的識別」 |

## 9. 平台合作客戶（中性敘述）

當客戶為 SHOPLINE / Shopify / 91APP / Cyberbiz / Wix：

| 情境 | 建議措辭 |
|------|---------|
| 平台限制範圍內優化 | 「在 [平台名稱] 平台的範圍內，可優化的方向包括 [Title 多樣性 / FAQ Schema / 文章內部連結結構] 等」 |
| 平台特色客觀化 | 「您的網站採用 [平台名稱] 平台，這是台灣常見的電商解決方案。基於該平台的固定模板特性，部分頁面結構可在範圍內進行 GEO 優化」 |

## 10. 雙品牌 / 多品牌共存

| 情境 | 建議措辭 |
|------|---------|
| 雙品牌共存 | 「網站同時存在 [品牌 A] 與 [品牌 B] 兩個產品線，但缺少 llms.txt 向 AI 說明品牌架構，AI 難以精確識別品牌主體」 |
| 商品命名不統一 | 「品牌商品命名疑似存在多個版本，可能影響 AI 統一識別品牌的能力」 |

## 11. AIO / GEO 策略類

| 情境 | 建議措辭 |
|------|---------|
| AIO 觸發但品牌引用率低 | 「品牌相關關鍵字疑似已觸發 AIO，但 AI 引用的疑似為競品內容，建議從內容深度與結構化資料切入，提升品牌被引用機會」 |
| 延展性關鍵字布局不足 | 「品牌目前佈局的關鍵字類型疑似偏向 [描述]，建議調整方向至 AIO 難以完整回答、使用者需進站深入了解的『延展性關鍵字』」 |

## 12. 報告結尾的 CTA 標準寫法

### ✅ 建議寫法
- 「期待與您進一步討論 GEO 優化的具體執行方向」
- 「awoo 顧問團隊可為您提供量身規劃的 GEO 優化方案」
- 「歡迎透過 [聯絡方式] 與我們的 AE 團隊洽談」

### ❌ 避免寫法
- 「立即聯絡」「立刻行動」「機會稍縱即逝」（過於行銷化）
- 「不採取行動將造成嚴重損失」（恐嚇式）
- 「保證 X 倍流量提升」（過度承諾）
