# Prompt 雙倍候選池邏輯

> 為什麼要產 2 倍候選池、如何分配、如何讓客戶挑選。

---

## 1. 為什麼是 2 倍候選池

### 核心邏輯：給選擇空間

如果客戶要 90 條最終 Prompt，直接產 90 條：
- 客戶失去選擇權
- 不符合品牌偏好的字必須照單全收
- 客戶無法依「市場熱度」「業務優先順序」自行調整

產 2 倍（180 條）候選池：
- 客戶從 180 條中挑 90 條
- 不需要的可以剔除
- 可保留「策略性 Prompt」與「一般 Prompt」的混搭比例

### 不要超過 2 倍

3 倍以上會讓客戶選不完、決策疲勞。2 倍剛好是「**有得挑但不混亂**」。

---

## 2. 分配公式

### 已知條件
- 客戶選定的關鍵字數：N 個
- 客戶最終要的 Prompt 數：M 條

### 計算每個關鍵字產幾條
```
每字產出條數 = (M × 2) / N
```

### 範例
- 客戶選 30 個關鍵字，最終要 90 條 Prompt
- 每字產出條數 = (90 × 2) / 30 = 6 條
- 每字 6 條 = 探索 2 + 決策 3 + 品牌 1（標準比例）

### 邊界情況
- 每字 < 4 條 → 增加每字條數，否則三意圖無法均衡
- 每字 > 7 條 → 客戶可能想精簡關鍵字數量，先確認

---

## 3. 三意圖分配範例（每字 6 條）

| 意圖 | 條數 | 範例 |
|------|------|------|
| 探索型 | 2 | 「葉黃素是什麼？對眼睛有什麼幫助？」「葉黃素的種類有哪些？」 |
| 決策型 | 3 | 「請推薦 5 款適合上班族的葉黃素」「比較不同品牌葉黃素的成分差異」「我預算 1000 元以內，葉黃素該選哪一款？」 |
| 品牌型 | 1 | 「[品牌名] 葉黃素的特色與其他品牌的差異是什麼？」 |

## 4. 比對客戶內容承接的邏輯

### 對每條 Prompt 執行比對

```python
import json

# 載入客戶的 RAG chunks
chunks = []
with open('_rag_chunks.jsonl', 'r') as f:
    for line in f:
        chunks.append(json.loads(line))

# 對每條 Prompt 進行語意比對
for prompt in prompt_pool:
    # 萃取 Prompt 中的關鍵概念
    keywords = extract_keywords(prompt)
    
    # 查找客戶內容是否有承接
    matched_chunks = []
    for chunk in chunks:
        if any(kw in chunk['content'] for kw in keywords):
            matched_chunks.append(chunk)
    
    # 標註結果
    if len(matched_chunks) >= 2:
        prompt['coverage'] = 'good'  # ✅ 已有充足承接
    elif len(matched_chunks) == 1:
        prompt['coverage'] = 'partial'  # ⚠️ 部分承接
    else:
        prompt['coverage'] = 'none'  # ❌ 無承接，需補內容
```

### 報告中呈現方式

每條 Prompt 旁標註：
- ✅ 已有承接（內容深，AI 容易引用客戶頁面）
- ⚠️ 部分承接（內容存在但深度不足）
- ❌ 無承接（需補新內容才能被 AI 引用）

讓客戶看到 Prompt 與內容缺口的對應，引導下一階段的內容規劃。

## 5. 客戶挑選的「決策框架」

報告中應提供決策框架，幫客戶從 2 倍候選池挑選：

### 決策維度 1：意圖比例
- 業務優先 → 提高決策型比例
- 品牌建立 → 提高品牌型比例
- 知識教育 → 提高探索型比例

### 決策維度 2：內容承接狀況
- 優先選 ✅ 已有承接的 Prompt（短期可見效）
- 中期計畫 ⚠️ 部分承接的 Prompt（補內容後可見效）
- 長期布局 ❌ 無承接的 Prompt（要新建內容）

### 決策維度 3：競爭性
- 高競爭主題 → 多選品牌型，搶佔差異化位置
- 低競爭主題 → 多選決策型，主動推進

## 6. 不挑「四不像」Prompt

過濾原則：

### 過濾掉太通用的
- ❌ 「葉黃素好嗎？」（太短，意圖不明）
- ✅ 「請問葉黃素對於長期使用 3C 產品的人有幫助嗎？」

### 過濾掉太特殊的
- ❌ 「請問星期三晚上吃葉黃素配紅茶會怎樣？」（過於荒謬）

### 過濾掉沒有商業意義的
- ❌ 「葉黃素的化學結構是什麼？」（純學術，無商業）
- ✅ 「葉黃素是什麼成分？吃多少有效？」

## 7. Prompt 寫作模板

### 探索型模板
- 「[主題] 是什麼？[延伸詢問]」
- 「[主題] 有哪些 [類別/種類]？」
- 「為什麼要 [動作]？[主題] 對我有什麼幫助？」

### 決策型模板
- 「請推薦 [N] 款 [情境/族群] 的 [主題]」
- 「我想 [動作]，[主題] 該怎麼挑？」
- 「[主題 A] 和 [主題 B] 哪個比較適合 [情境]？」
- 「我預算 [金額]，[主題] 該選哪一款？」

### 品牌型模板
- 「[品牌名] 的 [主題] 和其他品牌相比有什麼差異？」
- 「[品牌名] 是什麼樣的品牌？他們的 [主題] 表現如何？」
- 「我看到 [品牌名] 的 [產品]，請問值得買嗎？」
