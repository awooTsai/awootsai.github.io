# Prompt 候選清單拓展核心規則

> 沿襲 ada-geo-prompt-builder v3.x 規則。

---

## 1. 拓展目的

將客戶選定的關鍵字延伸成「**真人會問 AI 的完整問句**」，作為 GEO Suite 追蹤的 Prompt 候選池。

最終客戶會從候選池中挑選正式上線追蹤的 Prompt 數量（如 90 條）。

---

## 2. 候選池數量規則

### 總候選池 = 待選數的 2 倍
- 客戶最終要 90 條 → 產 180 條候選
- 客戶最終要 60 條 → 產 120 條候選

### 每個關鍵字延伸 4-7 條 Prompt
- 4 條：基本（覆蓋三意圖）
- 5-6 條：標準
- 7 條：複雜主題（多面向需要追蹤）

### 每組關鍵字至少有 1 條品牌型
- 確保品牌被提及機會
- 強化品牌在 AI 回答中的露出

---

## 3. 三意圖分類

### 探索型（Exploration）
- 使用者剛開始研究問題，還在了解
- 範例：「葉黃素是什麼？對眼睛有什麼幫助？」

### 決策型（Decision）
- 使用者準備購買，在比較選擇
- 範例：「我想買葉黃素，請推薦 5 款適合我的品牌」

### 品牌型（Brand）
- 使用者已知道品牌，想深入了解
- 範例：「[品牌名] 的葉黃素和其他品牌相比有什麼差異？」

詳細各類型的範例與寫作技巧見 `customer-journey/` 下三個檔案。

---

## 4. Prompt 撰寫風格鐵律

### 必須是真人問句
- ✅ 「我想找適合熬夜上班族的葉黃素，有什麼推薦？」
- ✅ 「請列出 5 款適合 50 歲長輩的葉黃素品牌」
- ❌ 「葉黃素 推薦 上班族」（這是搜尋關鍵字，不是 Prompt）

### 完整問句
- ✅ 完整的句子，有主詞、動詞
- ❌ 只有片語

### 口語化
- ✅ 「請推薦」「我想買」「想了解」
- ❌ 過於生硬的書面語

### 字數
- 探索型：15-30 字
- 決策型：20-40 字
- 品牌型：20-50 字

---

## 5. 比對客戶現有內容

若使用者提供 `_rag_chunks.jsonl`，每條 Prompt 需比對：
- 客戶網站是否有對應內容承接此 Prompt
- 沒有對應內容的 Prompt 標記為 ⚠️「需先補內容」
- 有對應內容的 Prompt 標記為 ✅「已有承接」

讓客戶看到 Prompt 拓展與內容缺口的對應。

---

## 6. 三意圖比例建議

| 意圖 | 標準比例 | 高轉換產業（電商）建議 | 知識型產業（金融、教育）建議 |
|------|---------|---------------------|--------------------------|
| 探索型 | 30-40% | 30% | 40% |
| 決策型 | 40-50% | 50% | 35% |
| 品牌型 | 20-30% | 20% | 25% |

服務型品牌（律師、醫師）建議：探索 35% / 決策 40% / 品牌 25%。

---

## 7. 報告呈現方式

每組關鍵字呈現結構：

```
[主關鍵字] (搜量 X)
└─ 探索型（X 條）
   • Prompt 1（已有承接 ✅ / 需補內容 ⚠️）
   • Prompt 2
└─ 決策型（X 條）
   • Prompt 3
   • Prompt 4
└─ 品牌型（X 條）
   • Prompt 5
```

每條 Prompt 提供「一鍵複製」按鈕。

---

## 8. 報告檔名

- 檔名：`{品牌英文 slug}_prompts_{YYYY-MM-DD}.html`
- ASCII only

---

## 9. 與其他 Skill 的銜接

```
ada-geo-keyword-research
   ↓ 客戶選好字
ada-geo-prompt-builder（本 Skill）
   ↓ 客戶選定 Prompt
GEO Suite 追蹤工具
```

報告結尾應提示：
> 「選定的 Prompt 將上線 GEO Suite，每週追蹤 ChatGPT、Gemini、Perplexity 等 AI 引擎中您品牌的能見度與引用率。」
