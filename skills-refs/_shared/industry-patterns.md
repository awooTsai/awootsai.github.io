## §1 電商 / 服飾 / 包袋類（PORTER、GU 案例精煉）

### 1.1 常見診斷重點

| 觀察點 | 業務提案版說法 | 專員執行重點 |
|------|------------|------------|
| 商品分類頁 Title 含目標關鍵字 | 「分類頁標題疑似缺少高搜量延伸字」 | Title 模板：`[主關鍵字]/[延伸字 A]/[延伸字 B] - 品牌名` |
| 知識/穿搭文章與商品頁的內部連結 | 「文章與商品的連結布局疑似不夠系統」 | 文章末尾「相關商品」區塊、文章中段自然 CTA |
| 分類頁下架後的 301 處理 | 「曾有 SEO 流量的分類頁疑似已下架」 | 301 到替代分類，重新上架時沿用原 URL |
| Product Schema 完整度 | 「商品頁的價格、現貨狀態結構化資料疑似不完整」 | price、priceCurrency、availability、aggregateRating 完整填寫 |
| 季節性/年份關鍵字更新 | 「2024/2025 年款式關鍵字疑似未更新至 2026 年版本」 | Title/H1 年份同步更新，dateModified 結構化資料同步 |
| 商品款式不多但顏色/變體多 | 「為提升分類頁競爭力，可考慮為商品變體獨立設置頁面」 | 將「包包-5色」拆成 5 個獨立頁，提升分類頁 SKU 數 |
| 文章新鮮度 | 「部分文章疑似有時效性問題，建議確認標題年份」 | 詳見 `_shared/awoo-knowledge.md` 文章新鮮度章節 |

### 1.2 高風險訊號

電商類常見的「明顯異常」訊號：
- Title 多樣性 < 90% → 大量頁面用模板標題
- Meta Description 多樣性 < 70% → 商品頁共用描述（PORTER 多次發現）
- Product Schema 覆蓋率 < 80% → 商品頁缺結構化標記
- 文章標題仍含「2024 年」「2025 年」（已過期）

### 1.3 三波關鍵字策略對應

電商類關鍵字拓展常見模式：
- **順風波段**：商品大類字（如「牛仔褲」「肩背包」）→ 客戶已有商品但 Title 未優化
- **補強波段**：知識型字（如「牛仔褲穿搭」「包包保養」）→ 文章太少
- **攻堅波段**：季節/趨勢字（如「2026 春夏新款」）→ 完全沒切入

### 1.4 業務提案版的痛點優先順序

電商業務提案版健檢三大痛點建議：
1. Meta Description 多樣性低 → 商品差異化不足
2. 知識文章承接 AIO 流量不足 → 機會錯失
3. 商品變體頁面策略 → 競爭力提升空間

## §2 金融 / 保險 / 投資 / 外匯類（中信 i 外匯案例精煉）

### 2.1 常見診斷重點

| 觀察點 | 業務提案版說法 | 專員執行重點 |
|------|------------|------------|
| FAQ 頁面是否有 FAQ Schema | 「FAQ 頁面疑似缺少 FAQ 結構化資料」 | FAQ Schema JSON-LD 完整建置 |
| 文章 dateModified 同步 | 「結構化日期疑似未同步更新」 | 每次更新文章必同步 dateModified |
| 「延展性關鍵字」內容布局 | 「目前內容偏向解答型，可加強複雜問題」 | 詳見 §2.3 |
| 服務頁是否有獨立 URL | 「多個服務疑似共用單一 URL，AI 難以分別排名」 | JS 切換內容 → 改為獨立 URL |
| AIO 引用內容缺口 | 「AI 回答相關問題時，疑似引用競品而非自身內容」 | 詳見 §2.4 |

### 2.2 金融業的「延展性關鍵字」框架

**不值得重點佈局的字（會被 AIO 秒殺）**：
- 有明確唯一答案（如「美元現在多少錢」）
- 純列表型查詢（如「外幣定存利率排行」）
- 答案簡單，使用者不需進站就能解決

**值得重點佈局的字（延展性）**：
- 涉及「選擇」「成本評估」的複雜問題
- 例：「外幣定存到期後該怎麼辦」「美元升值時要不要轉手」
- 使用者需依自身情況判斷的問題

### 2.3 文章優化的 AIO 導向策略（中信實戰）

**目標**：讓文章被 AIO 引用

**執行步驟**：
1. 分析目標關鍵字的 AIO 引用內容（截圖記錄競品被引用段落）
2. 找出品牌文章缺少的 H2/H3 段落
3. 補充對應段落（可用 AI 生成草稿，請客戶確認正確性）
4. 確認 FAQ Schema 正確設置
5. 更新 dateModified

**實際案例**：「外幣定存到期後」
- 分析 AIO 引用了哪些競品頁面段落
- 發現文章缺少「外幣定存到期後 5 大方向」「Q4：注意事項」
- 新增對應 H2/H3 段落
- 更新 FAQ Schema 加入 Q4

### 2.4 金融業務提案版的痛點優先順序

1. FAQ Schema 缺位 → AI 引用機會錯失
2. 「延展性關鍵字」內容布局不足 → 進階消費者問題沒接住
3. 文章新鮮度與更新頻率 → 金融資訊時效性高

## §3 服務型（律師 / 醫師 / 顧問 / 教育機構）類（京宇法律案例精煉）

### 3.1 服務型最重 E-E-A-T

服務型品牌的 GEO 健檢，**E-E-A-T 是第一優先**：

| 觀察點 | 業務提案版說法 | 專員執行重點 |
|------|------------|------------|
| 律師/顧問個人頁 ProfilePage Schema | 「專業人員介紹頁疑似缺少 ProfilePage 結構化資料」 | 完整 ProfilePage JSON-LD（含 alumniOf、sameAs） |
| 個人頁論文/文章/社群連結 | 「專業人員頁疑似缺少 sameAs 連結」 | sameAs 連結至學術論文、媒體、社群 |
| Organization Schema | 「品牌組織結構化資料疑似未設定」 | 首頁 head 區塊 Organization Schema（含地址、電話、logo） |
| 客戶見證/民眾回饋頁 | 「客戶見證頁面疑似缺少結構化的引用標記」 | 量化呈現（XX 則回饋、滿意度 XX%） |
| 首頁傳達品牌差異化 | 「首頁疑似未明顯傳達服務特色」 | Hero 區、X 大理由、服務流程等模組化 |
| 文章內 CTA | 「文章內疑似缺少明顯 CTA」 | 中段 Banner、文末諮詢按鈕、浮動 CTA |
| 競業特色分析 | 「競業疑似有更明確品牌定位」 | 觀察競業 Banner 訊息、特色溝通方式 |

### 3.2 服務型品牌的首頁優化模板（京宇實戰）

```
1. Hero / Banner 區塊（強化品牌特色訊息）
2. 「選擇 [品牌] X 大理由」區塊（H2 設置）
3. 「[服務名稱] 流程」區塊（H2 設置）
4. 「專業團隊」區塊（補充團隊特色簡述）
5. 「成功案例」區塊（H2 設置，民事/刑事/家事等分類）
6. 「客戶見證 / 民眾回饋」區塊（量化呈現）
```

### 3.3 服務型的進階外連策略：連結誘餌（京宇實戰）

**A. 範本/資源頁面**（門檻低）
- 法律：離婚協議書、民事起訴狀、車禍求償明細表
- 通用延伸：報價單範本、合約範本、SOP 範本

**B. 小工具/計算器**（門檻高，但效益最強）
- 法律：賠償金計算器、合約產生器、AI 法律諮詢
- 金融：利息試算、貸款計算器
- 電商：尺碼推薦、穿搭風格測驗

**C. 研究洞察/實驗數據/行業調查**（門檻高）
- 法律：「台灣十大離婚原因」「車禍賠償金額調查報告」
- 各產業可衍生

**D. 當事人故事分享**（需當事人同意）
- 第一人稱角度，更具情感共鳴

**E. 公共熱門話題**（需即時性）
- 將專業領域結合時事議題

**F. 資訊圖表（Infographics）**
- 將複雜資訊視覺化，容易被引用與分享

### 3.4 服務型業務提案版的痛點優先順序

1. Organization Schema + ProfilePage Schema 缺位 → AI 識別專業權威不足
2. 首頁差異化溝通不明確 → 轉換率低
3. 客戶見證頁缺少結構化 → E-E-A-T 訊號弱
4. 文章內 CTA 不夠醒目 → 諮詢轉換流失

## §4 中古車 / 媒合平台類（HOT 大聯盟案例精煉）

### 4.1 常見診斷重點

| 觀察點 | 業務提案版說法 | 專員執行重點 |
|------|------------|------------|
| 廠牌頁 vs 型號頁的著陸頁 | 「『廠牌+二手車』關鍵字疑似著陸於型號頁而非廠牌頁」 | 麵包屑、頁底連結、H2 集中信號 |
| 動態參數 URL 重複內容 | 「同一頁面疑似透過多個 URL 變體被索引」 | 詳見 `_shared/seo-best-practices.md` URL 一致性章節 |
| 麵包屑連結 canonical 一致 | 「麵包屑連結疑似指向非主要版本網址」 | 確認所有內部連結指向 canonical 版本 |
| 「地區+關鍵字」著陸頁策略 | 「地區型關鍵字的著陸頁可能未針對該意圖優化」 | 城市分區頁、地區關鍵字布局 |
| HTML Sitemap 一致性 | 「HTML Sitemap 疑似指向錯誤版本網址」 | 統一指向 canonical 版本 |
| 雙 H1 / 隱藏 H1 問題 | 「部分頁面疑似存在多個 H1」 | 系統共用 H1 改 span/p、保留唯一頁面專屬 H1 |

### 4.2 中古車業務提案版的痛點優先順序

1. 廠牌頁 vs 型號頁的著陸頁衝突 → 排名信號分散
2. 動態參數 URL 重複內容 → SEO 權重稀釋
3. 廠牌頁缺真實 H1 → 主題識別弱

## §5 日文網站 / 海外類

### 5.1 日文網站特殊規則

- 全文使用日文商務 keigo（です・ます體）
- CTA 連結 → `https://awoo.ai/ja/`
- 字體建議 Noto Sans JP
- 標籤 AI 推論為「awoo コンサルタントによる推定」
- ASCII-only 檔名

### 5.2 多市場品牌（如 PORTER 跨日台市場）

- Hreflang 設定鐵律：`zh-TW` ↔ `ja` 互相指向，`x-default` 指向預設
- 每個語言版本各自完整（不可只有部分頁面有對應）
- 翻譯品質：避免機翻直譯，需在地化（特別是行銷文案）

## §6 其他健檢實戰客戶補充（2026-05 累積）

### VIVANT Wine（葡萄酒科技品牌）
- 多市場（TW/SG/HK/JP/EU）→ Hreflang 是核心
- Product Schema 深度（年份、酒莊、葡萄品種）
- 多語言 GEO 策略

### Simmpo 簡單貼（保護貼領導品牌）
- FAQ noindex 封鎖 → AIO 機會直接斷線
- 商品頁 og-fallback H1 → 商品識別弱

### 淨淨 cleanclean（天然清潔保養）
- 知識型 AIO 強，品牌型空白 → 知識→品牌橋接策略
- 32 頁 E-E-A-T 頁缺 H1 → 品牌權威訊號斷裂

### ONE CHILLA 灣沏辣（手工生鮮辣椒醬）
- 雙品牌（灣沏辣/灣泮辣）共存 → llms.txt 必要
- 53% og-fallback H1 → 商品識別弱

### 台全牧場（雲林快樂豬直銷）
- **首頁 Title 異常**（設為「關於我們」）→ 罕見的最高優先問題
- 知識文章太少（3 篇）→ 55 個 AIO 增長受限

### Cloud Inc（質感 Bra Top）
- 26 頁 noindex 含廢棄測試商品「55 系列」
- 89 個 AIO 全是女性身體議題 → 知識→品牌橋接機會

## §7 跨產業共通的「平台合作客戶」處理

無論哪個產業，若客戶為 SHOPLINE / Shopify / 91APP / Cyberbiz / Wix 平台，**詳見 `_shared/platform-partners.md`**——必須遵守平台合作鐵律。

判斷平台時：
- liquid template 渲染（`Rendered '*.liquid'`、`{{ ... | translate }}`）= SHOPLINE 確認
- `/products/`、`/collections/`、`/blogs/`、`/pages/` 標準路徑 = Shopify
- 平台特有 URL 參數模式 = 91APP / Cyberbiz
- Wix 動態渲染重，URL 結構獨特
