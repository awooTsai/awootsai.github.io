# 關鍵字選字鐵則

> 阿達在所有過去拓字任務中強調的核心原則。
> 違反任一條 = 拓字結果作廢。

---

## 1. 五大鐵則

### 鐵則 1：字數越短越好

業主最在意的是「**有搜尋量**」的字。字數短 = 廣義 = 高搜尋量。

範例：
- ✅ 「葉黃素」（搜量高）
- ✅ 「葉黃素 推薦」（合理延伸）
- ❌ 「葉黃素 一天攝取量 推薦劑量」（過長，搜量被切碎）

### 鐵則 2：topic 主關鍵字 = 字數最短、搜尋量最高的廣義字

每個主題的「主關鍵字」必須是該主題下：
- 最廣義的字（不加修飾詞）
- 字數最少
- 搜尋量最高

### 鐵則 3：延伸字也優先選短尾

延伸字也應該是短尾通用字，**長尾字放後面**。

排序原則：
1. 主關鍵字（最短）
2. 一階延伸字（主字 + 1 個修飾詞）
3. 二階延伸字（主字 + 2 個修飾詞）
4. 長尾字（特定情境）

### 鐵則 4：禁止過長 / 冷門組合

完全沒有搜尋量的字 = **不要產出**。

如何判斷沒搜量：
- web_search 該字看是否有結果
- Google Autocomplete 不出現該字
- Ahrefs / Google Trends 顯示無數據

只要符合以上任一，剔除。

### 鐵則 5：每字都需驗證

每個產出的關鍵字都必須通過至少一種驗證：
- 搜尋量數據（Ahrefs / Google Trends / 任何工具）
- Google Autocomplete 出現
- 至少 1 個競業頁面有針對該字優化

## 2. 字數判斷指引

| 字數 | 判斷 | 範例 |
|------|------|------|
| 1-3 字 | 主關鍵字（最廣義） | 葉黃素、信用卡、二手車 |
| 4-6 字 | 一階延伸字（合理） | 葉黃素推薦、信用卡比較、二手車估價 |
| 7-10 字 | 二階延伸字（OK 但需驗證搜量） | 葉黃素一天攝取量、海外信用卡推薦 |
| > 10 字 | 長尾字（謹慎使用） | 通常搜量很低，需確認 |
| > 15 字 | 過長（剔除） | 搜量幾乎為 0 |

例外：法律 / 醫療等專業領域可能有較長的常見問題（如「車禍刑事責任有哪些」），但這類字本身就是常見問句，可放在「攻堅波段」配合文章操作。

## 3. 廣義 vs 精準的判斷

### 廣義字優勢
- 高搜尋量（流量基礎）
- 多元意圖涵蓋（攻擊面廣）
- AI 引擎在「OO 推薦」這類問句時偏好廣義字

### 廣義字劣勢
- 競爭高
- 客戶內容若不夠深，難以排名
- 需要長期投入

### 精準字優勢
- 競爭低
- 排名快
- 轉換率高

### 精準字劣勢
- 搜量可能不高
- 流量規模有限

### 三波策略對應
- **順風波段**：可放廣義字（已有內容基礎）
- **補強波段**：精準字 + 一階延伸（補完整）
- **攻堅波段**：廣義 + 高搜量字（要新建內容）

1. **第一優先**：阿達上傳的 Ahrefs CSV（如有）
2. **第二優先**：awoo_keywords.db 歷史記錄
3. **第三優先**：web_search 該字看搜尋結果頁
4. **第四優先**：Google Autocomplete 確認

至少符合一項才能寫進報告。

## 5. 從客戶內容 DNA 出發

### 識別客戶內容主題
讀 `_rag_chunks.jsonl`，標記：
- 各主題的頁面數量
- 各主題的內容深度（字數、H 標籤層級）
- 哪些主題有商品支撐 vs 純知識

### 從內容反推主關鍵字

範例：
```
客戶網站內容主題：
- 葉黃素相關（12 頁，含商品 + 知識文）
- 益生菌相關（8 頁，含商品 + 知識文）
- 魚油相關（3 頁，僅商品）
- 鈣片相關（1 頁，僅商品）

→ 葉黃素：可規劃完整三波（內容深）
→ 益生菌：可規劃順風 + 補強（內容中等）
→ 魚油：補強波段為主（缺知識文）
→ 鈣片：攻堅波段為主（要重建內容）
```

## 7. 平台合作客戶的特殊考量

當客戶為 SHOPLINE / Shopify / 91APP / Cyberbiz / Wix 平台：
- 拓字結果不受平台限制（關鍵字本身與平台無關）
- 但「對應頁面」與「技術優化建議」需考慮平台範圍內可執行性
- 例如：SHOPLINE 商品頁的 Schema 部分由系統自動生成，建議聚焦在 Title / Description 層面

## 8. 拓字結果的常見陷阱

### 陷阱 1：產出「人不會搜的字」
- ❌ 「葉黃素膠囊優質」（人不會這樣搜）
- ✅ 「葉黃素推薦」「葉黃素品牌」

### 陷阱 2：把品牌名當關鍵字
- 客戶品牌「OO 健康」這個字，月搜量可能只有 1000，但對品牌很重要
- 處理方式：放在「品牌字」分類，不混進拓字主結果

### 陷阱 3：跟風時下熱詞
- 「2026 葉黃素」這類年份字 → 短期有效，但不可作為主軸
- 應該是主字 + 延伸字 + （季節性年份字）的搭配

### 陷阱 4：忽略意圖
- 「葉黃素 副作用」與「葉黃素 推薦」是完全不同意圖
- 業主買「副作用」的字 → 流量不會轉換
- 業主買「推薦」的字 → 流量會帶來購買意圖
- 建議：拓字時標註各字的意圖類型（資訊/比較/購買）
